# DQ03 Remote (экспериментальная версия)

Приложение Android для ИК-передатчика (ConsumerIrManager). **Команды DQ03 не подтверждены**: три NEC-профиля — тестовые, могут не работать. Для настоящей совместимости потребуется запись оригинального пульта или подтверждённая таблица кодов.

## Сборка APK через GitHub
1. Создайте **публичный или приватный пустой репозиторий** на GitHub.
2. Распакуйте ZIP на ПК. В репозитории выберите **Add file → Upload files** и загрузите **содержимое папки** `DQ03-Remote`, включая скрытую папку `.github` (важно!). Если браузер не загрузил скрытую папку, создайте `.github/workflows/build.yml` через **Add file → Create new file**, вставив содержимое файла из архива.
3. Нажмите **Commit changes**.
4. Откройте **Actions → Build APK → Run workflow** (или дождитесь запуска после коммита).
5. Откройте успешный запуск и скачайте артефакт **DQ03-Remote-APK**. Распакуйте его: внутри `app-debug.apk`.
6. Перенесите APK на Xiaomi 14T, откройте файл и разрешите установку из этого источника, если Android запросит.

APK будет отладочным и подписан временным ключом сборки GitHub. Это нормально для теста, но не для распространения.

## Проверка
Направьте верх телефона на внешний ИК-приёмник DQ03, нажмите стрелку или POWER, попробуйте все три профиля. Успешная передача ИК **не означает**, что приставка поняла команду. Если нет реакции, нужен оригинальный код.
